# ADR-011: Establish SEO primitives at the application layer

## Status

Accepted

## Decision

Use Next.js metadata, sitemap, robots, semantic route structure, and branded social metadata as the baseline SEO layer. Editorial SEO will be added with the content system rather than scattered through individual components.

## Rationale

Tinlance needs search visibility across commercial services, technical research, and case studies. Centralizing the baseline keeps indexing and metadata behavior predictable.
