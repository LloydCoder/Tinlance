# ADR-009: Use solution-specific routes

## Status

Accepted

## Decision

Tinlance commercial capabilities use stable, descriptive routes under `/services/`, with dedicated pages for Autonomous AI, AI Infrastructure, AI Security, Automation, and Forward Deployed Engineering.

## Rationale

Each service needs a focused page for buyers, search engines, case-study cross-links, and future conversion experiments. Keeping these routes stable also lets the content system evolve without changing the commercial information architecture.
