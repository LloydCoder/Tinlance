# ADR-008: Keep the Tinlance application repository public

## Status

Accepted

## Decision

The main Tinlance repository is public, while secrets, customer data, private infrastructure, and proprietary client implementations remain outside the repository.

## Rationale

The repository is part of Tinlance's engineering credibility for prospective technical buyers. Public architecture, tests, documentation, and delivery practices demonstrate how the company builds without exposing operational secrets or client-confidential material.
