# ADR-022: Keep the homepage conversion path explicit

## Status

Accepted

## Decision

The homepage uses a primary assessment/conversation CTA and a secondary proof/content path. Both lead to stable routes rather than opaque client-side actions.

## Rationale

Tinlance needs the website to function as a demand-generation system. Clear CTAs make the commercial path measurable and preserve a useful non-sales path for technical evaluators.
