# Support

Tinlance is a public proprietary engineering repository. Use the channel that matches the problem.

| Need | Channel |
|---|---|
| Bug or reproducible product defect | [GitHub Issues](https://github.com/LloydCoder/Tinlance/issues) |
| Feature or engineering improvement | [GitHub Issues](https://github.com/LloydCoder/Tinlance/issues) |
| Documentation problem | [GitHub Issues](https://github.com/LloydCoder/Tinlance/issues) |
| Security vulnerability | [SECURITY.md](./SECURITY.md) |
| Conduct concern | [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) |
| Commercial/licensing inquiry | hello@tinlance.com |

Before opening an issue, search existing issues and read the repository documentation.

For implementation questions, include the exact commit, environment, command, expected behavior, actual behavior, and relevant non-sensitive logs.
